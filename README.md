## Featured Work

### 🏥 Telemedicine Platform
Secure video consultation platform for 2,000+ users — React Native, Agora SDK, NestJS, Redux Toolkit. AI-powered symptom chatbot. Built and shipped as team lead.

### 🤖 Smart Reply — AI Email Management
Enterprise email triage system with GPT-4o-mini intent detection, 3-tier risk scoring, and automated draft generation. Reduced manual processing by 70%. NestJS + Supabase + Gmail API + AES-256 encryption.

### 🌐 SimWise — Global eSIM Marketplace
4-service microservices monorepo integrating 8 global eSIM providers (Airalo, ESIMgo, Maya). Go-based gRPC gateway, Protocol Buffers, Stripe + Apple/Google IAP, Turborepo. Covers 180+ countries.

### ☁️ Airbin — AI Memory Cloud *(Co-Founder)*
SaaS platform combining persistent AI memory with AES-256 encrypted cloud storage (6GB–5TB) and multi-modal content generation. 4 subscription tiers. Next.js + React Native + NestJS.

### 🇬🇧 NINA & Dean Coffee — London Client
Full product suite for a London-based client: customer mobile app, admin dashboard, web frontend, NestJS backend. Reduced client manual workload by 60% through automated order management and Stripe integration. Delivered independently in 6 months, 100% on time.

### 🎵 ORIA — Music NFT Marketplace *(Live)*
Production blockchain marketplace with automatic wallet generation, PIN-secured NFT transfers, and Supabase Storage for audio. React + TypeScript + Nexus Blockchain.
